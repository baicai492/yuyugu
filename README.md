# 鱼鱼谷自动托管 v2（Node 主程序 + Chrome GUI）

针对 `52dmeme.com/pets`（鱼鱼谷）的全自动托管程序。

**架构**：所有游戏逻辑跑在 **Node 主程序**里（直连站点 HTTP、复用站点线上规则模块做本地预演），
Chrome 插件只做 **GUI**（连本地端口看状态、市场预测、改设置、看日志）。
这样绕开了 MV3 后台保活、service worker 回收、跨域等限制。

## 为什么用 Node 而不是 Python

价格公式、结算公式、五子棋 AI 全在站点前端的 `pet-world-rules.js` 里（1495 行）。
Node 能**直接 import 这一份文件**，本地预演与真实结算逐字一致；
换成 Python 就要移植 1500 行，站点每次更新（本次就改了 65 处）都得重抄一遍，抄错就是错判。

```
  npc.mjs                52弟（五子棋求解 + 其他小游戏）
  gomoku.mjs             五子棋求解器（多路线试走，只提交复盘验证过必胜的棋谱）
  arena.mjs              擂台（挑战、宝箱、换装、加点、训练）
  social.mjs             串门（帮忙、偷菜）

```

## 安装

1. Node 18+（本机 v24）。
2. cookie：把浏览器里登录后的 `sid=...` 放进 `../messages/cookie.txt`（默认路径，可在配置里改）。
3. 启动主程序：

   ```
   node yuyugu2.mjs          # 或双击 start2.bat
   ```

4. 装 GUI（可选）：Chrome → `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选 `gui/` 目录。

## 用法

### 一键启动（推荐）

装好 GUI 后**不需要敲命令**：打开插件，如果显示「主程序没有运行」，点 **启动主程序** 即可。

首次需要注册本地宿主（只需一次）：

```
node scripts/install-host.mjs --ext-id=<你的扩展ID>
```

扩展 ID 在 `chrome://extensions` 里能看到。脚本会生成 `.bat` 包装器并写入注册表
`HKCU\Software\Google\Chrome\NativeMessagingHosts`（Edge 同样写一份）。

**不做开机自启** —— 主程序只在你点按钮时才启动；插件关掉后它继续在后台跑。
卸载：`node scripts/install-host.mjs --uninstall`。

### 改完代码怎么让它生效

`启动`/`暂停` 只是切换「做不做动作」，进程里的代码没变。改了 `core/*.mjs` 之后必须重启进程：

- **GUI**：概览页点 **重启**。主程序会先 spawn 一个新进程再自己退出，面板自动重连（约 3 秒）。
- **命令行**：`Ctrl+C` 停掉，重新 `node yuyugu2.mjs`。

### 主程序（命令行方式）

| 命令 | 作用 |
|---|---|
| `node yuyugu2.mjs` | 持续托管 + 启动本地服务（默认 8787） |
| `node yuyugu2.mjs --once` | 只巡视一次 |
| `node yuyugu2.mjs --dry` | 演练：只打印计划，不提交任何动作 |
| `node yuyugu2.mjs --market` | 打印市场预测报告后退出 |
| `node yuyugu2.mjs --test-gomoku 3 20` | 离线测五子棋（难度 3，跑 20 局） |
| `--port=8787` | 指定本地服务端口 |
| `--no-server` / `--no-console` | 不启服务 / 不启命令行控制台 |

有 TTY 时可以直接在终端敲：`start` / `stop` / `once` / `status` / `market` / `save` / `quit`。

### GUI

弹窗四个标签页：

- **概览**：今日净增、D币、库存、岛上时间、体力、规模、本岛日额度、收支明细、启动/暂停/巡视一次/重启
- **市场预测**：供需反推 + 未来岛日商闻 + 择时卖出表（现价%、峰值%、几个岛日后、卖线、建议）
- **设置**：常用开关与数值，保存后主程序热生效
- **日志**：三个模式
  - **本次运行**：当前进程的实时日志
  - **历史记录**：磁盘上最近 1–30 天的日志（重启、换版本都不丢）
  - **旧插件记录**：直接读旧版 Chrome 插件存在浏览器里的历史日志
    （自动扫描 Chrome/Edge/Brave 所有 profile 的 `Local Extension Settings`，不写死路径）

## 托管做什么

按优先级：

1. **领奖类**（零成本）：夜潮小礼、守家补偿、每日目标
2. **成熟即收**：作物、畜产、蟹笼——这是防偷的唯一可靠手段
3. **牧场**：喂食（攒够 8 小时就能续）、每天摸摸
4. **浇水**：没有洒水器的地
5. **补种**：当季最优作物 + 若干块口粮田
6. **投资**：只买预计 5 天内回本的（地块/工具/蟹笼/畜栏），每次巡视最多投一项
7. **加工**：有正毛利就做
8. **花体力**：在钓鱼/挖矿/炸矿里挑单位体力收益最高的，直到额度或体力用尽
9. **囤货**：判定「等峰值更划算」的货锁进仓库
10. **卖货**：只在价格接近未来峰值时卖，尊重作物阶梯价与累进税
11. **货船**：基础价进货，预期能加价卖出才买
12. **52弟**：五子棋（困难档 ×1.5，每天前 10 局计奖）
13. **擂台**：打满 30 场掉落、开 5 个宝箱、自动换装加点
14. **帮忙**：每天 10 家（200 D + 2 经验/次）
15. **偷菜**（默认关）：盯名单记下每块地的精确解禁时刻，到点按期望收益抢

## 关键机制（详见 MODULES.md）

- **体力是硬约束**：上限 100（小屋每级 +20），180 秒回 1 点。冰美式 +60 且**可超上限**，是唯一突破口。
- **市场完全可预测**：价格 = 基础价 × 日期哈希因子 × 商会事件 × 供需。
  前三项只依赖日期，未来任意岛日的基准报价能精确算出；唯一未知是供需（钳位 0.80–1.06），用当天报价反推。
- **卖出有三层成本**：作物阶梯价（150 全价 / 400 内 85% / 之后 70%）、累进卖货税（300 万以上 1%，1000 万以上 3%）、
  自我砸盘（今天卖太多，明天这个物品的供需被打到底）。
- **五子棋必胜**：服务端 AI 确定性，本地走完一整局再提交。实测 60 条路线 × 抖动 0.5：
  简单 20/20、普通 18/20、困难 19/20。**只提交复盘验证过的棋谱**，输的线直接弃掉。
- **偷菜**：成熟后 30 分钟保护期，过了就人人可偷；每处体力 +1（5–15），被发现要打守家战，输了按市价 1.2 倍赔（单次上限 5000）。
  访问邻居时用 `state.plots[].t`（种植时刻）加生长时长、再加保护期，能算出精确解禁时刻——包括「已经成熟、还在保护期」的地；
  畜栏则按窝里第二个产物出现的时刻算。每座岛只排「最早一组合格目标」，解禁前十几秒醒来、访问完直接提交，
  不再等下一次到点扫描。

## 配置

`config.json`（只在和默认值不同时写盘）。GUI 的设置页可以直接改。
常用项：

- `invest.maxPaybackDays` / `invest.reserveCoins`：投资门槛与保留现金
- `sell.horizonDays` / `sell.markdownPct`：往后看几个岛日、离峰值差几个点就卖
- `npc.gomokuLevel`：1/2/3 对应倍率 0.8/1.2/1.5
- `social.steal.enabled`：偷菜开关（默认关）
- `arena.battles`：每天打多少场擂台（前 30 场有掉落）

## 安全

- cookie 只在本地读取，不写日志、不进 git（`.gitignore` 已排除）。
- 本地服务只监听 `127.0.0.1`，且校验 Origin 白名单；可用 `--token=xxx` 再加一层。
- `--dry` 演练模式可以完全不提交，用于站改版后验证。

## 已知限制

- 偷菜默认关闭：需要擂台等级支撑，否则赔钱。
- 管家（服务端自带的挂机）和本程序**共用**体力与每日额度。如果同时开，两者会互相消耗；
  建议在线时用本程序，离线时段交给管家（`scripts/set-butler.mjs`）。
- 五子棋不是 100% 必胜：小概率整批 60 条路线都没找到胜局，此时程序会**跳过这局重开**，不提交输棋。
