# 斗法托管（图像识别版）

修仙试炼 ·「弹幕斗法」的**真打**托管：不伪造请求、不注入页面脚本、不改游戏状态，
就是盯着屏幕看，判断弹幕往哪飞，然后把鼠标指针挪到安全的位置。

* 前台：Chrome 插件（状态、开关、日志）
* 后台：本地 Python 进程（抓屏 → 识别 → 决策 → 动鼠标）

和鱼鱼谷主程序（`gui/` 的 Node 托管）**完全独立**，不共用端口、不共用配置。

---

## 为什么是这条路

弹幕斗法是纯前端判定（`new4/xs/danmaku.js`），服务端只认「起止时间 ≥ 关卡下限」
和「符卡收取数上限」。想自动打，最稳的路子就是**真的去打**：
像素里看得见的，机器人就能躲；网页自己算的胜负，网页自己提交。

这也避开了禁区——不碰 `xsFight / xsWin / xsLose / xsRoot / xsStory`
这五个禁止提交的动作。

## 怎么跑

1. **起后台服务**（装了 opencv/numpy/mss 的那个 Python）

   ```
   danmaku\启动.bat            :: 或者  python start.py
   ```

   窗口会打印 `弹幕托管服务已启动：http://127.0.0.1:8799`。

2. **装插件**：Chrome → `chrome://extensions` → 打开「开发者模式」→
   「加载已解压的扩展程序」→ 选 `danmaku/` 目录。

3. 打开斗法页面，进入战斗，点插件图标 →「开始托管」。

窗口可以缩到后台，但**不能被别的窗口盖住**（盖住了就看不到弹幕了）。

## 工作原理

```
mss 抓屏 ──► 找 #b77732 棕框（场地定位）──► 裁剪 + 2 倍放大
                                              │
        ┌─────────────────────────────────────┴──────────────┐
        │ HSV 双阈值 → 连通域 → 距离变换找弹芯峰值（每颗弹一个峰）│
        │ 细长条 → 激光；无芯大块 → 敌机（接触判定 size*0.25）  │
        │ (8,6)-(376,12) 血条 → Boss 血量 / 是否 Boss 战        │
        └─────────────────────────────────────┬──────────────┘
                                              │
              最近邻贪心跟踪（穿自机挖空区的弹靠速度外推）│
                                              │
        枚举 24 方向 × 3 半径的候选落点，沿飞行路径模拟 0.45 秒 │
        取「全程离所有威胁最近距离」最大的那个 ──────────────► SetCursorPos
```

* **自机怎么控制**：游戏里自机是「朝鼠标指针匀速飞」（300 逻辑像素/秒），
  所以唯一控制量就是指针位置。
* **开火**：这个游戏是自动射击，不需要点鼠标。右键是符卡（清屏保命），
  余量实在不够时才会放。
* **自机会被挖掉**：自机的鲸鱼雪碧图和敌弹阈值区间完全重叠，
  不挖掉机器人会躲自己；挖掉以后靠轨迹外推继续跟踪穿过去的子弹。

```
danmaku/
├── manifest.json / popup.* / content.js / background.js   插件（前台）
├── start.py / 启动.bat                                     起服务的入口
└── python/
    ├── server.py     本地 HTTP 服务（只监听 127.0.0.1:8799）
    ├── engine.py     主循环：状态机、受击判定、符卡、结束判定
    ├── vision.py     屏幕识别：场地、敌弹、激光、敌机、血条
    ├── ai.py         多帧跟踪 + 走位决策
    ├── io_win.py     抓屏（mss）与鼠标注入（ctypes，不用装 pyautogui）
    ├── sim.py        离线模拟器（把 danmaku.js 的核心动力学搬过来）

```

## 离线自测

不用开浏览器、不用登录：

```
cd danmaku\python
D:\miniconda\envs\py311\python.exe selftest.py           :: 200 秒虚拟时间的一局
D:\miniconda\envs\py311\python.exe selftest.py --dump D  :: 存标注图，肉眼看识别对不对
```

最近一次结果：

```

```

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 演练模式 | 关 | 只识别不动鼠标。第一次用建议先开，确认「敌弹/敌机」数字和画面相符 |
| 自动放符卡 | 开 | 最优路线的余量也不到 3 像素时放符卡清屏 |
| 预判时长 | 0.45 秒 | 看多远。短一点更保守，长一点更早转向 |
| 反应 | 标准 | 放大安全余量（灵敏 = 更贴弹，稳 = 离弹更远） |
| 识别帧率 | 30 | 每帧约 20~25 毫秒 |

## 已知限制

* **暗场阶段**（魔修长老第 3、4 幕、雷属性切磋第 3 幕）：游戏只给自机和 Boss
  周围挖个洞，外面全黑。看得见的半径约 90 逻辑像素，等于把预判距离压到
  0.3~0.6 秒，这一段会比平时危险。
* **判定点**：游戏里真正的判定半径是 2.2 像素（`d < b.r + 2.2`），
  机器人按「保守膨胀」的半径算，比真人更怕死，偶尔会为了躲一颗远弹而
  跑到更差的位置。
* 一局打完**不会**自动点「再来一局」——那属于操作游戏界面，不在本程序范围。
* 需要游戏窗口可见（不能最小化、不能被完全遮住）。插件可以放后台。
